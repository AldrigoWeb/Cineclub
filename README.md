# Cineclub
1. **TMDB**: crea un account su themoviedb.org, poi Impostazioni > API e copia il "Token di accesso in lettura".
2. **Supabase**: crea un progetto gratuito, apri SQL Editor e incolla `supabase/schema.sql`. Copia Project URL e la chiave `service_role`.
3. Copia `.env.example` in `.env.local` e compila i 4 valori.
4. `npm install` e `npm run dev`, poi apri http://localhost:3000
5. Online: carica la cartella su GitHub, importala su vercel.com e inserisci le stesse 4 variabili in Settings > Environment Variables.
